# رواتب الموظفين — الإصدار 3

تطبيق Android لإدارة الموظفين والرواتب والحضور اليومي.

## الحساب التلقائي
عدد أيام الشهر يؤخذ من التقويم الميلادي: 28 أو 29 أو 30 أو 31.
أجر اليوم = الراتب الأساسي ÷ عدد أيام الشهر.

عند تسجيل الحضور:
- حاضر: أجر اليوم مستحق.
- غائب: يخصم أجر اليوم.
- نصف يوم: يخصم نصف أجر اليوم.
- إجازة مدفوعة: بدون خصم.

الراتب الشهري يبقى ثابتاً، ويتغير أجر اليوم حسب عدد أيام الشهر.
